# 验收与完成报告

- principle: 所有结果写 PASS、FAIL、NOT_CHECKED 或 NOT_APPLICABLE，并指出实际证据。未执行的检测不能标 PASS；不要求无关产品或用户没要求的设备。

## 验收表

| 项目 | 合格证据 | 不能用来替代的信号 |
| --- | --- | --- |
| 配置语法及实际加载 | 当前版本原生配置校验通过，运行实例已加载该配置 | 文件写入成功或启动图标 |
| Claude 实际路由 | 在网站、API、Desktop/Code 的本次相关请求中核对真实连接/策略链及目标出口 | 普通 IP 网站、某个策略组名字或地区标签 |
| 固定出口 | 切换其他产品的出口后，目标流量仍由固定策略处理 | 一条泛用“走代理”规则 |
| 上游故障不直连 | 在已有安全恢复能力下，限定目标故障后连接拒绝、无 DIRECT 回退；恢复后正常 | DNS失败、HTTP 401/403 或原节点还正常 |
| 隧道退出边界 | 用户要求时另验隧道完全退出后的目标行为，并确保控制与恢复不受损 | 隧道运行时的 fail-closed 结果 |
| DNS 与 IPv6 | 对相关客户端查解析路径和实际连接；如禁 IPv6 则验证对应路径未绕行 | 只看到一个 IPv4 出口 |
| WebRTC | 浏览器实际候选地址与路由符合所选策略，网页通话回归正常 | 只跑 curl，或把私网/mDNS当公网泄漏 |
| 规则更新保留 | 现有更新机制仍可用，一次获准更新/渲染后目标覆写仍生效 | 全部禁用更新或只写了本地文件 |
| 其他业务不受损 | 对本轮可能影响的既有直连/代理用途作最小验证 | 把全机都强制走一个节点 |
| 登录与账号 | 官方客户端/页面显示本人登录及实际账户状态 | HTTP 200、代理握手或替用户生成的账号资料 |
| 订阅和付款 | 用户已授权的订单/收据及账号权益实际读回 | 卡片提交、扣款处理中或网页回跳 |
| 隐私偏好 | 目标账号当前选项已按本人要求保存 | 配置隐藏 IP 或防封推断 |
| 恢复和清理 | 原配置可核对恢复；临时材料按归属清理，必要备份独占且位置明确 | 把 apply-files 或 rollback 成功当运行态已恢复 |

## 新资源与设备验收

| 项目 | PASS 条件 |
| --- | --- |
| VPS 及账单 | 实例 ID、地域、套餐及实际费用符合授权；无重复资源 |
| SSH 与防火墙 | 已验证主机身份；配置后可新建 SSH 管理连接；只开放必要端口 |
| VPN | 两端独立密钥及地址正确，近期握手和实际传输可见 |
| 固定 IP | 当前实际出口与预期地址相同；地址生命周期及费用已确认 |
| 系统持久性 | 配置已保存、自启动已启用；真实重启仅在执行过时标通过 |
| 邮箱与 MFA | 本人可登录和收信，恢复方式已验证 |
| 手机号 | 目标设备兼容、激活完成、实际普通短信及需要的产品验证成功 |
| 付款 | 原订单明确成功、实际对应产品权益读回、续费选择符合要求 |
| 手机 VPN | 本设备专属 peer，实际产品请求、Wi-Fi/蜂窝及 IPv6 边界已核对 |

只验收本次要求的分支，没要求买 VPS、手机号时标 NOT_APPLICABLE；不是为了凑表格而多买东西。输出不附完整资源 ID、账号、号码或支付资料，必要续接信息留在本人既有受保护位置。

## 脚本探测边界

- inspect: 仅检查环境元数据和文件存在性，不读取秘密值、不访问账号、不执行网络检查。
- probe: 对明确指定的 HTTPS URL 做 HEAD 请求，跟随最多三次 HTTPS 跳转，curl 总截止加外层进程截止；不带 Claude 登录凭据。HTTP 401/403/405 仍可能表示收到服务器响应，不证明登录或路由正确；不能据此把故障拒绝验收标通过。
- apply: 写入前预检全部目标，备份并保留原权限，精确散列读回；实际运行时是否采用由 AI 另验。更换一个文件的内容不意味着系统级路由、DNS、浏览器或服务已改。

## 最终消息

```text
状态：COMPLETE / PARTIAL / BLOCKED
目标：实际授权的电脑与产品
已完成：具体配置及对应验收结果
未完成：真实缺口、是否阻塞、必要本人操作
费用：已授权预算、已核实实际消费及续费状态
恢复：本轮事务 ID、私密恢复入口、运行态恢复方式
清理：本轮临时材料的处理及必要保留项
```

- closing: 无需每个步骤反复向用户汇报。完成及真实阻碍时简洁说明；后台状态、账号停用或未确认付款不能当全部成功。
