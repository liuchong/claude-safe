# 邮箱、手机、账号和支付

## 1. 邮箱

1. 优先使用本人长期控制的现有邮箱，先确认能正常收信。没有时选择本人可合法注册的邮箱服务，使用真实资料和独立密码。
2. 在官方注册表单完成本人验证；收邮件后只在原站点输入验证码或打开确认动作，不把验证码复制进对话。
3. 开启 MFA，保存恢复代码，确认恢复邮箱/号码确属本人。发送一封普通测试信并收到回复，检查垃圾箱和账户恢复入口可用。
4. 浏览器登录由本人账号完成，不导入他人会话。不要为了所谓“养号”发送垃圾邮件、设置虚假年龄或批量注册。

## 2. 是否需要新号码

1. 先看实际产品注册/登录流程是否真的要求号码；没有要求就不购买，不把美国出口推导成必须美国手机号。
2. 已有本人长期号码且能满足当前验证要求时直接复用。需要新号码时选由本人持有、可续费、能恢复的运营商实体 SIM 或 eSIM，不能用共享接码、租用一次性短信或他人实名号。
3. 区分“纯流量 eSIM”与“有真实号码且支持短信/语音的套餐”；前者通常不能接验证码。供应商写支持 SMS 也不保证目标服务接受该号段，付款前核对限制和退款条件。

## 3. 购买 SIM/eSIM

1. 在手机设置查看准确型号、地区版本、SIM 锁状态和 eSIM 支持。设备具有 IMEI 不证明支持 eSIM；找不到“添加 eSIM”且型号不支持时选实体 SIM，不买写卡器冒充通用解决方案。
2. 查看套餐号码国家、有效期、激活期限、所在国家能否远程激活、漫游覆盖、Wi-Fi Calling 要求、短信收发、是否含号码、续费金额与失效回收规则。
3. 在供应商正式店面选择“新号码/新激活”而不是只适用于老用户的续费券。确认设备兼容、总价和本人的预算；姓名、地址和账单资料真实填写，不编造运营商要求的地址。
4. 本人在支付页面完成付款。保存订单入口和到期日到既有密码/订阅管理工具；不把完整收据和手机号写入本仓。
5. 收到激活邮件后，核对原订单和激活码，不点击来源不明的附件。若需要 IMEI，使用目标手机本人的真实 IMEI，在供应商表单输入，不交给聊天。

## 4. 激活与实测

1. 手机接稳定 Wi-Fi，电量充足，保留原主卡；新增线路不能先删除原卡。按运营商激活页选择新号码或明确授权的携号转入，不擅自发起转号。
2. 输入激活码及目标设备信息，提交一次，等待原订单显示激活完成。系统要求本人身份验证时由本人完成。
3. 打开“设置→蜂窝网络/移动网络→添加 eSIM”；在同一手机上用供应商 App 或系统导入，或扫描在另一已授权屏幕显示的二维码。二维码本身是敏感安装凭据，不截屏到报告、不公开传送。
4. 线路标签设为能区分的工作号码；主数据默认保留原卡。只有套餐允许且本次需要时打开新卡漫游或 Wi-Fi Calling，不能承诺无额外费用。
5. 先接收一条普通短信、发出一条可计费预算内的测试短信，必要时做一次短通话；检查实际计费。再在目标产品要求的流程做一次验证码验证。
6. 无服务时先看激活状态、套餐覆盖、设备锁、漫游开关；有服务无短信时查套餐和目标号段支持。不能用反复发送验证码掩盖不支持，达到限流停止等待原倒计时。
7. 本人确认接受后才考虑将此号码设为恢复方式；先保存 MFA 恢复代码。设置续费提醒或获准自动续费，失效前迁移重要账号；不让号码回收后仍绑定敏感账号。

## 5. Claude 注册、登录和隐私

1. 在官方应用或站点，确认实际产品及本人地区资格。优先已有账号，登录后查看真实状态，不复制 Cookie、设备 ID 或第三方令牌。
2. 缺少账号时使用上述邮箱和本人资料注册；若页面要求手机、验证码、CAPTCHA 或身份核验，按实际表单完成，不虚构必填项，也不绕验证。
3. 只修改本人明确要求的隐私设置，例如对话用于改进服务的偏好；保存后重新进入设置读回。隐私选项不隐藏网络出口，不代替账号资格。
4. Code、Desktop、网站和 API 的授权/计费可能不同，逐一确认实际需要哪一种。不能用网站订阅收据推断 API 余额或反过来。

## 6. 信用卡、订阅和应用商店

1. 优先使用本人合法持有且允许线上/跨境/周期付款的信用卡或借记卡。核对可用额度、币种、外币费用、3DS 及自动续费，不因为网络出口在美国就要求假美国账单地址。
2. 当前卡不支持时，先联系发卡行或让本人选择可用的正规支付方式；不得替本人开虚假身份金融账户、买卖卡片或使用来路不明的代充。
3. 在实际付款页查看本产品的套餐、周期、税、总价、续费日与退款/取消条件，和授权预算比较；不把历史价格、地区价或网页会员套到另一个产品。
4. 卡号、有效期、CVV、账单地址由本人在官方受保护页面或系统钱包输入，AI 不读取/保存。3DS、银行 App 确认及生物识别由本人完成。
5. 点击付款一次后，核对订单、扣款状态和实际账号权益。超时、预授权、pending 或回跳不是失败证明；先查原订单再决定是否重试，避免重复订阅。
6. 使用应用商店时核对当前商店账号、真实地区、支持的付款方式及订阅归属；不为折扣切换到虚假地区。只有当地规则和实际商品支持时才使用本人获得的礼品卡余额，不购买可疑卡或承诺一定能支付周期订阅。
7. 若同一账号已有网页或商店订阅，先查旧周期及取消状态，不自动叠加第二份。付款成功后查看权益、续费日和管理入口，再做最小实际产品使用验收。
8. 不需要续费且用户已授权时在原渠道关闭自动续费，读回有效截止日；关闭续费不等于立即退款。退款或争议只基于真实情况，不教唆虚假拒付。

## 7. 交付与保留

1. 报告只写邮箱/号码/付款状态及是否本人已完成，不含完整账号、手机号、订单号或支付信息。
2. 现行凭据放密码管理器或系统安全存储；删除本轮多余截图、邮件导出和临时二维码。必要合同、收据由本人保存在原服务账户或自己的正式存档。
3. 账号停用、资格不符或支付未完成明确为 PARTIAL/BLOCKED；网络配置成功不能替代这些验收。
